# Mockups conceptuels TONDE

Ces visuels sont des placeholders de démonstration pour la landing page officielle TONDE.

## Statut
- `mobile-app-concept.svg` : concept de l'application mobile
- `desktop-guichet-concept.svg` : concept du poste guichet desktop
- `tv-display-concept.svg` : concept de l'affichage TV salle d'attente
- `admin-dashboard-concept.svg` : concept du dashboard d'administration

## Règle de remplacement
Chaque fichier peut être remplacé plus tard par un mockup haute fidélité ou une capture réelle, sans modifier le code applicatif tant que le nom du fichier reste identique.
